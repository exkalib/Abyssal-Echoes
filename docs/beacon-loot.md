# 信标掉落规则

信标是普通物资的补充来源，不是剧情道具或权限的替代来源。

- 共 69 种普通物资：43 种材料（含原料、加工品、弹药与食材）、17 种补给/料理、9 种普通工具/防护组件。
- 材料、补给和工具池在 1 / 3 / 5 / 8 / 12 / 20 / 40 / 60 / 80 层累积扩充；高层仍能掉落低阶物资。每次抽取多种物品，不是每次发完整物品表。
- 原有基础材料保底保留，额外抽取 4–10 种不同材料，其中优先给最多两种当前阶段的新材料；另抽取 1–3 种补给。数量随层数适度增加，工具组件持有后不重复掉落。
- 技能书、装备与精通手册均保留。每 5 层装备保底，每 10 层额外保底一本普通技能书；其他层随机掉落。精通手册每次保底，每十层增加一本。阵列升级的技能书掉率 +5% 实际生效；概率不超过 100%。
- 普通装备沿用现有分层装备池。剧情钥匙、门禁/权限凭证、核心证据、教程道具、飞船剧情组件、星门密钥全部排除；所有结局奖励（包含专属装备）从 `ENDINGS` 自动纳入禁入名单。
- 结算只入包并解锁下一信标层，不赋予剧情凭证、不改任务完成标记、结局或地图发现状态。剧情仍须按原流程探索、对话、交付和完成。
- 任意层仍固定消耗 1 个信标电池，不消耗入场体力。旧存档中正在进行的信标战按层数使用新池，无需清档或迁移。
- 选层、展开图鉴及显示/关闭奖励不调用抽奖，不二次发奖。采集增产只作用于材料，不放大书、装备、补给或工具数量。

配置位于 `BEACON_LOOT_TIERS` / `BEACON_STORY_ITEMS`；新增物品须明确归入普通物资层级或剧情禁入名单，覆盖测试会检查遗漏。

验证：`node prototype/game.test.js --beacon-loot-only`（4,000 次固定随机序列与结算回归）。浏览器验证：`prototype/beacon-loot.browser.test.cjs`，使用独立临时浏览器，不操作玩家存档。
