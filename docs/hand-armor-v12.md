## 动效规则

`wardrobe-hand-effects.js` 从已挂载的手掌、指节、护臂图层读取源坐标，复制同一矩阵和部位裁切。相位腕甲不能被摆动后的袖子遮住；握枪不会残留旧空手；卸下时全部对应光效清除。

场能以局部呼吸为主；量子增加少量相位粒子；星际晶核与指节能量更清楚。每部件最多两个粒子、双手最多八个，无 JS 逐帧循环，不在手套外套全身光圈。

装甲 `wardrobe-fx.js` 跳过 hands / cuff / grip，避免重复。共用最近祖先 `data-fx-quality="high|low|off"`、减少动态与文档隐藏暂停；普通刷新保留同一动画时间轴。
