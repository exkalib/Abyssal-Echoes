# 职业战斗基线 v1

2026-09-05，本地未发布。对应 `prototype/combat-balance.cjs` 和 `combat-balance.test.cjs`。

## 这轮修正

旧中后期敌人攻击力低于同阶段防具提供的防御，大量攻击只触发 1 点保底伤害，再生/吸血轻易抹平全部损耗。盾卫的防护优势和装备升级因此没有实际意义。

本轮只按时代与敌人定位修改固定基础攻击力，不读取玩家属性动态缩放；敌人生命、防御和特殊机制不变。地图首领详情现在展示实际攻击、防御、生命和备战参考，等级提示不是新的进入门槛。

| 敌人 ID | 新基础攻击 |
| --- | ---: |
| guardian / arsenalWarden | 120 / 140 |
| echoBeast / echoLeviathan | 175 / 450 |
| scrapDrone / vacuumInterceptor / relayCorsair | 360 / 420 / 800 |
| lunarCrawler / massDriverAI / outpostRaid | 850 / 1800 / 1300 |
| xenoStalker / livingBulwark / planetaryCrown | 1300 / 1500 / 2500 |
| phaseSentinel / gateCustodian | 2200 / 3000 |

盾击命中现在积累 1 格动能，未命中不积累。动能反击的基础威力为 `max(总攻击, 总攻击 × 0.5 + 总防御 + 最大护盾 × 0.75)`，之后沿用技能倍率和敌人减伤。换上更好的盾不再被单纯武器攻击值盖掉收益。面板展示同一计算结果。

三路线的见习训练统一在教程结束后的老乔处开放，正式导师、任务和转职仪式不变。模拟第二时代的猎手使用见习职业，不提前赠送深层才可取得的正式资格。

## 可复现边界

测试加载真实 `game.js`，使用真实敌方行动、命中、护盾、状态、技能与资源规则；仅替换渲染和战斗结束后的奖励/死亡页面副作用。每组使用 64 个分散种子，覆盖所有 25 种敌人与 3 路线，共 4,800 场。

这是**同阶段准备充分的首轮回参考配装**，不是所有配装穷举，也不是完整探索流程自动通关。算法是可读的技能循环策略，不是最优解搜索。

- 普通敌人第一时代 Lv5，首领 Lv8；后续各时代 Lv12 / 18 / 24 / 30 / 36 / 42。
- 正式职业等级 3 / 5 / 6 / 8 / 9 / 10，精通 3 / 5 / 8 / 12 / 16 / 20；早期见习不预授终结技。
- 逐时代只解锁配装实际所需科技及前置；基因只用首轮回可合法取得的节点，并验证等级、击杀、科技与剧情门槛。
- 每场起始弹药 40、武器电芯 48、医疗包 2、体力药 2；无食物增益、EMP、轨道支援和复活。
- 治疗必须使用真实战斗物品动作，会推进回合并承受反击，不能在战斗中免费调用背包使用。
- 每次 HP / 护盾 / 体力写入分别记账；治疗不能冲掉此前承伤记录，药品不能掩盖体力支出。

## 当前参考结果

所有普通敌人与首领在上述配装下均 64/64 胜利，无耗材不足后的无效循环或超时。下表为平均回合数，不含胜利后的探索消耗。

| 首领 | 舰盾路线 | 游骑路线 | 猎手路线 |
| --- | ---: | ---: | ---: |
| riftMatriarch | 24.8 | 18.7 | 17.5 |
| arsenalWarden | 14.7 | 7.7 | 10.4（见习） |
| guardian | 9.4 | 5.9 | 7.6（见习） |
| echoLeviathan | 12.5 | 4.9 | 3.6 |
| relayCorsair | 10.4 | 4.0 | 5.0 |
| massDriverAI | 9.2 | 4.0 | 5.0 |
| outpostRaid | 6.7 | 3.0 | 3.0 |
| planetaryCrown | 14.2 | 8.0 | 6.0 |
| gateCustodian | 24.6 | 12.0 | 9.2 |

终局首领：三路线平均最低生命比例为 88.0% / 74.9% / 71.5%；舰盾平均体力支出 111.8，游骑平均消耗 36 电芯，猎手平均体力支出 54.4。这里体现的是防御稳定、弹药输出与近战风险的取舍，不能把“胜利时满血”当作从未受到攻击。

## 防回归与后续边界

自动断言：普通敌人胜率 100%、首领至少 90%；普通敌人最长 12 回合、首领最长 36 回合；首领平均至少 3 回合；无卡死、无负消耗、弹药/电芯不超过携带预算；真实装备兼容、基因门槛、种子可重复；后期首领造成实际承伤且调用终结技。

仍需结合玩家反馈检查低配、提前挑战、长途连续探索补给和多轮回高精通。上述测试不会掩饰这些尚未穷举的情况；新增敌人必须加入同一矩阵，新增装备必须提供合法阶段配装与材料获取测试。
