# 装备视觉进阶 v12

本轮目标是改善套装原画的整体感，并让科技等级从轮廓、材质和动态能量三方面可辨认。不是给原图加同一种发光描边。装备 ID、数值、制造成本、解锁与存档兼容保持不变，原有腰裆、领口和靴口接合必须继续验收。

## 统一视觉层级

| 阶段 | 形体和材质 | 能量表现 | 背部轮廓 |
| --- | --- | --- | --- |
| 锻造 | 耐用织物、清楚的保护片、少量磨损 | 不加悬浮粒子 | 实用负重背架 |
| 舰装 | 精密加工、紧凑动力结构 | 少量实体指示灯 | 机械储能背架 |
| 场能 | 更完整的装甲面、清晰能量核心 | 局部呼吸灯、少量导轨流光 | 紧凑双推进翼 |
| 量子 | 高级复合材、分段机翼、磁悬浮结构 | 定向光脉冲、有限能量粒子 | 展开的分段量子翼 |
| 星际 | 具有辨识度的主装甲轮廓、稀有材质、明确核心 | 高能核心、翼端轨迹和推进粒子 | 多片轨道翼，不能超出人物舞台 |

专精路线以冷白 / 铂银、黑钛、电青与钴蓝为主；综合路线以珍珠白、深钛、香槟金和青金能量为主，量子阶可少量使用紫色。禁止所有阶段都同样发光、所有物品都套一种颜色。前期保留实用定位，后期减少随机铆钉、裸露管线、大片安全橙和脏斑，增强有方向性的完整装甲面。

## 原画与穿戴

- 每件仍使用独立原画；胸甲男女单独适配，裤装从腰到踝整件绘制，不退回腰部补丁。
- 风格编辑优先锁定已有外轮廓、领口与腰口坐标。生成后必须实际核验透明像素与人体接缝，不能用提示词承诺替代检查。
- 新背装为机械 / 能量机翼，不是羽毛或魔法天使翅膀。脊柱安装点位于背部，双翼在身体之后。翼端避开头部和 UI，中央机匣不压到人物胸前。
- 图标必须同步对应的新物品原画。更换外观不改 ID、不增减装备、不改变存档。

## 动效约束

- `wardrobe-fx.js` / `wardrobe-fx.css` 统一实现服装、背翼、模组等效果；武器和手部由 `wardrobe-weapon-effects.js`、`wardrobe-hand-effects.js` 分别负责。全部挂在同一个穿戴成功入口，根据实际图层及其变换生成效果，不能在角色页和背包各写一套，也不能给握姿重复叠加光效。
- 按单件真实阶段触发，混搭也有效，不要求凑满套装。核心、装甲导轨、手部节点、鞋推进口、模块和翼端采用不同形态与节奏。
- 特效节点与装备图层分离，不重建人物节点，不篡改骨骼或装备变换。卸装清除对应效果，连续切换以最后一次选择为准。
- 限制总粒子与层数，以 CSS 动画为主。不可见、切换标签和隐藏页面时暂停；尊重减少动态效果设置，并提供低质量 / 关闭模式。
- 禁止快速高频闪烁、全身白闪、遮住脸的光团、覆盖属性文字的大雾，以及每次点击重播整个人物入场动画。

## 验收

逐件查看初始 / 三职业男女的单穿、同套和混搭。测试透明与装配、人物身份不变、两页完全一致、卸装恢复、快速连续选择、360 / 390 / 520 宽度，以及不同时间帧确实有动画而非静态截图。光效正确不代表原画好看，原画漂亮也不能代替移动端性能检查。

## 本轮完成范围

已实装第三至第五阶的专精 / 综合六套：12 张男女独立胸甲、6 张完整裤装、6 张双靴、6 张机械翼，共 30 张新穿戴资产，覆盖 24 件装备。第一、二阶继续保留实用风格。配套六款手部装备的 18 张原生透明握姿由并行任务完成，见 [手甲说明](hand-armor-v12.md)。没有把未重绘的头部、盾牌或模块称为新原画。

用户明确授权“沿用上次本地处理，完成实装”。30 张衣甲 / 靴 / 翼中，3 张翼为原生透明，另外 27 张仅本地处理预留背景及边缘透明度，未重画装备像素或上传到其他服务；全部解码验证真实 RGBA。这是本批例外，不放宽后续素材的默认规则。
