# 手机文件存档修复（外壳 12）

原因：旧安卓 WebView 没有系统下载或文件选择器接入，网页 Blob 下载没有可靠保存结果。复制完整密文另加 Base64 后更长，不适合作为聊天消息迁移。

本轮：
- 外壳 12 提供 backupFile 桥，使用系统 ACTION_CREATE_DOCUMENT 选择保存位置，写入并关闭成功后回报文件名；取消和失败独立反馈。
- ACTION_OPEN_DOCUMENT 读取玩家选择的文件，限制 8 MB，在后台线程读写；仍由现有加密校验、预览、二次确认完成导入。
- 不开放 WebView 的任意文件访问，不增加存储权限，不改云端 localhost/file 限制，不改 v2 加密格式。
- 页面优先文件保存，支持系统文件分享的浏览器另提供分享按钮；其他浏览器明确提示查看下载记录，不声称已经落盘。安卓保存后可从文件管理器将文件发送到 QQ / 微信。
- 旧外壳显示需要安装新版 APK，提醒不要卸载。页面热更新无法补齐安卓文件能力。

验证：game.test.js 通过；backup-files.browser.test.cjs 在隔离 Quark 浏览器通过下载、旧壳提示、模拟原生成功/取消/失败及重试、导入解密预览。安卓全部 Java 源码通过 Android 36 SDK 的 javac 编译。

限制：没有连接真机；系统选择器真实交互尚未实机验证。后续 0.7.15 发布构建已通过 Maven 镜像补齐 Gradle 依赖，使用外壳 12、安装版本 21 打包。签名更新清单要求外壳 12，不能仅发资源包；真机保存、取消、文件往返仍需设备验收。页面最低运行外壳保留 11，使旧页面仍能说明具体文件功能缺失，而非无条件封锁游戏。
