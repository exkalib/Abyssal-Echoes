## 本版内容

- 第三至第五阶专精 / 综合六套科技装备重新绘制：男女胸甲、完整裤装、靴子和机械背翼成套，越后期越突出科技轮廓与能量表现。
- 新增随实际装备部位运动的呼吸光、流光和动态粒子；武器、手甲与服装分别采用对应效果，隐藏、卸装及减少动态效果设置均正确处理。
- 全部裤装采用连续腰裆原画，修正裤腰衔接、渲染横暗线及鞋靴后沿叠在前方的问题；角色和背包共用穿戴图层。
- 武器按类型适配握持与托枪姿态，后期手甲配套更新；保留双手武器与盾牌互斥规则。
- 缩小营地标题，固定设施标题和筛选区域；调整设置的内部滚动、声音操作、存档入口与底部返回操作。
- 装备 ID、数值、材料消耗、解锁和存档格式不变，新素材同步图标。
