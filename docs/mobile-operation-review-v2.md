- [《暗黑破坏神：不朽》官方装备设计说明](https://news.blizzard.com/en-us/article/23574266/itemization-in-diablo-immortal)：把基础属性、附加属性和特殊效果分层。本轮借鉴信息层级：候选物品只呈现识别信息，选中后显示主要变化，需要时再展开全部词条。这是历史技术测试版设计资料，不作为当前数值依据。
- [《暗黑破坏神：不朽》官方无障碍设计说明](https://news.blizzard.com/en-us/article/23805083/making-a-game-for-everyonediablo-immortals-accessibility-features)：关注手机操作位置与可读性。本轮把确认动作留在底部，并检查真实可点击区域，不照搬其可配置按键系统。
- 保留本作冷色科幻材质、职业立绘和技能纹章，不新增后台式数据概览页。

## 最终交互

### 背包

- 顶部四种物品分类，中间四至五列物品格内部滚动，底部选中物品与快捷动作固定。
- 首次优先展示物品，不让完整立绘把短屏压到一行物品；点“查看穿戴”展开，点“收起立绘”返回整理。用户的显式选择会保存，分类切换、换装和重启不自动改变它。
- 默认全部装备，可按部位筛选；格子仅保留原画、名字、数量与穿戴标记。
- 点物品只选中；底部“穿戴 / 卸下 / 使用”才执行。主要属性及同部位差值即时显示，下一件直接点，不必先关弹窗。
- 点底部物品信息才打开完整属性、兼容条件、比较和来源。角色页仍有完整人物展示；背包展开时沿用同一穿戴系统，头部两侧浮物不加框。
- 连续操作保留候选节点、当前选中和列表位置；分类及部位切换保留本页的各自列表位置。
- 精通手册的“选择精通”直接进入统一技能页，进入不消耗；选定能力与数量后才研读。快捷入口和完整详情共用此流程，不再打开用后数量失效的旧研读弹层。
- 满血、满体力、库存耗尽、技能满级、不适用道具与双手武器冲突等条件原位说明并禁用，不通过失效点击来解释。

### 职业

- 顶部只有主战职业、生活专精两类；底部三个路线纹章选择，中间只展示当前选中的一条。
- 主战显示真实职业立绘；生活专精采用紧凑纹章与能力列表，不替换角色身份。
- 下一步与学习、晋升、转职按钮固定在下方。选择路线只预览；执行仍检查导师位置、任务、材料、等级与重构核心。
- 当前职业可以直接前往相应技能分类；详细成长与资格就地展开。生活专精仍可三种并行，相关作业能力不用装备进战斗槽。

### 技能

- 主动技能、自动生效、基础精通分开。默认已学技能，明确勾选后才显示未学技能与获取条件。
- 三列能力库内部滚动；点选只更新下方常驻详情，不弹抽屉。能力库保持原节点及滚动位置。
- 当前效果与升级结果并列：技能书按实际增加 20 熟练度计算；精通手册按选定数量预览，基础精通仍无等级上限。
- 主动技能下方只保留一套三技能栏，点目标栏直接装配、点本技能所在栏卸下。被动与生活能力没有误导性的装配动作。
- 研读、数量及确认固定在底部；耗尽显示缺少道具，按钮不跳位置。

### 一致的反馈

上述原位操作直接更新穿戴、数量、等级与状态，不再弹重复成功 toast 挡住按钮。错误提示、战斗和 NPC 场景原有必要反馈保留。

### 底栏视觉收尾

- 三页固定确认动作统一为 48px 高、文字居中、完整细边框与小圆角，不再叠加切角和圆角造成边线残缺。
- 背包“穿戴 / 使用”采用青色能源材质，“卸下 / 查看来源”用较低强调的金属灰；禁用态明确区分。
- 选择条左右留白 12px，物品原画在 44px 容器内保留四周 6px 内距；不裁切或改动实物图。
- 底栏为属性差值预留相同空间，穿戴前后不因文案换行而上下移动按钮或挤动列表。
- 360px 技能页的使用条件完整可见；更长的详情仍在自身内部滚动。能力库显示实际数量，溢出时明确提示继续上滑。
