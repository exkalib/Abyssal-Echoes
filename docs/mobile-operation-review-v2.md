2026-09-07，本地修改，尚未发布。游戏数值、转职资格、NPC 与材料门槛不变；不重做人物或装备原画。

## 单张战技场景（取消三分类页，尚未发布）

- 删除顶部三个分类标签及背后的三套分类页。主画面只挂载战技库、当前招式投影和三个装配位；自动能力、基础精通改为场景右侧纵向独立图标，点击打开浮层。
- 能力列表 → 单项详情 → 返回列表均在浮层中完成，不改主画面选择、装配或滚动位置。精通手册从背包直接打开对应的研习详情，不再切换整页分类。
- 主画面默认已学战技，技能图鉴只展开未学战技；自动能力列表不受主画面的图鉴开关影响。基础精通保持无等级上限。
- `npm test`、四尺寸技能专项、跨面板回归和背包专项通过，覆盖 360×640 / 390×844 / 412×915 / 520×844。测试断言没有分类标签（包括隐藏节点），主画面只有一个技能库，并验证真实研读消耗、Lv152、浮层防穿透及返回状态。实际截图：`output/skills-scene-v2/`。
- 遵循 `karpathy-guidelines`，仅更改展示与入口，未调整数值、材料消耗或解锁门槛；使用隔离测试存档，没有改动玩家存档。

## 技能招式投影页（上轮记录，分类结构已被上节替代）

- 主画面改为分类 → 当前技能投影及效果 → 四列已学纹章 → 固定战斗槽与研习入口。保留舰桥场景，不新增在线图片；视觉以技能独立 SVG、语义光色、斩击 / 齐射 / 护盾 / 相位投影为主体。
- 主画面不再生成升级对比表、数量输入或获取规则折叠表。点击图标只选择，三个战斗槽继续直接装配 / 替换 / 卸下；槽位显示实际技能图标。自动能力和精通不提供装配槽。
- 明确点「招式研习 / 能力详情 / 研习精通」才打开手区抽屉。沿用原效果计算、技能书 +20 熟练度、精通每本 +1 级及数量上限检查；弹层内固定操作，关闭保留主画面的选择、图标节点和滚动状态。
- 切换到不同技能才播放一次 0.55–0.65 秒入场；装配、卸下、研读和重复点选不重播。遵守减少动态效果设置，没有定时轮播或持续粒子循环。
- `npm test`、四尺寸技能专项、跨面板回归和背包专项通过。测试覆盖 360×640 / 390×844 / 412×915 / 520×844，验证真实装配、书本耗尽、精通 Lv152、未学禁用、弹层防穿透及背包入口。实际截图：`output/skills-attunement-v1/`。遵循 `karpathy-guidelines`，本轮不调整技能数值、解锁条件或玩家存档。

## 当前职业身份页（替代下面旧职业目录方案，尚未发布）

- 不再生成三条主战路线预览，也不再划分主战 / 生活两页。始终读取当前主战职业的真实 ID；旧存档中停留在其他路线的预览选择不会影响显示。
- 主画面为当前职业的完整男女立绘、名称、介绍、等级与经验，职业固定值和百分比属性加成合并到同一属性行。未就职显示幸存者与老乔教学线索，不自动授予职业。

- 学习和普通转职回到对应 NPC 的职业训练界面；已有特殊仪式资格会在地下信号源出现现场入口，继续校验装备、材料和跨路线重构核心消耗，避免移除目录后断掉晋升路径。
- `npm test`、跨面板浏览器回归与职业专项通过；职业专项覆盖 360×640、390×844、412×915、520×844，检查真实属性、灰色槽禁用、详情关闭、NPC 入门、仪式消耗及三职业男女共六张立绘。截图：`output/career-identity-v1/`。遵循 `karpathy-guidelines`，没有调整职业数值、经验公式、任务条件或玩家存档。

## 0.7.15 后的场景化视觉调整（上轮记录，职业部分已被上节替代）

上一轮手机操作改动已随 0.7.15 发布。用户继续指出网页工具感，这一轮单独处理视觉：

- 背包使用现有生活舱场景，装备与人物保留原位置与比例，物品仓去掉巨大的实体外框，改为场景上的暗色透明托底。
- 职业页使用反应堆场景，人物宽度从舞台 48% 增至 68%，让完整立绘成为前景主体；文字用局部暗衬保护阅读。
- 技能页使用舰桥场景；选中只点亮技能纹章，去掉外层选中卡片与遗留装饰边线。
- 没有新增动画循环、在线资源、道具、能力或操作步骤；复用 APK 已有场景图片。背景不会移动玩家或解锁地点。
- 独立预览位于 `output/game-ui-scene-v1/`；接入后的真实回归截图位于 `output/game-ui-scene-final/`。修改仍遵循 `karpathy-guidelines` 的局部变更与真实验证约束。
- 接入后通过 `npm test`，以及职业、技能、背包和跨面板浏览器回归；覆盖 360、390、412、520 像素宽度。人工检查了 390 像素的三页截图，确认人物前景、局部文字暗衬和透明物品仓效果；测试使用隔离存档，没有改动玩家存档。

## 最终交互

### 背包

- 顶部四种物品分类，中间四至五列物品格内部滚动，底部选中物品与快捷动作固定。
- 首次优先展示物品，不让完整立绘把短屏压到一行物品；点“查看穿戴”展开，点“收起立绘”返回整理。用户的显式选择会保存，分类切换、换装和重启不自动改变它。
- 默认全部装备，可按部位筛选；格子仅保留原画、名字、数量与穿戴标记。
- 点物品只选中；底部“穿戴 / 卸下 / 使用”才执行。主要属性及同部位差值即时显示，下一件直接点，不必先关弹窗。
- 点底部物品信息才打开完整属性、兼容条件、比较和来源。角色页仍有完整人物展示；背包展开时沿用同一穿戴系统，头部两侧浮物不加框。
- 连续操作保留候选节点、当前选中和列表位置；分类及部位切换保留本页的各自列表位置。
- 精通手册的“选择精通”直接进入统一技能页，进入不消耗；选定能力与数量后才研读。快捷入口和完整详情共用此流程，不再打开用后数量失效的旧研读弹层。
- 满血、满体力、库存耗尽、技能满级、不适用道具与双手武器冲突等条件原位说明并禁用，不通过失效点击来解释。

### 职业

- 顶部只有主战职业、生活专精两类；底部三个路线纹章选择，中间只展示当前选中的一条。
- 主战显示真实职业立绘；生活专精采用紧凑纹章与能力列表，不替换角色身份。
- 下一步与学习、晋升、转职按钮固定在下方。选择路线只预览；执行仍检查导师位置、任务、材料、等级与重构核心。
- 当前职业可以直接前往相应技能分类；详细成长与资格就地展开。生活专精仍可三种并行，相关作业能力不用装备进战斗槽。

### 技能

- 主动技能、自动生效、基础精通分开。默认已学技能，明确勾选后才显示未学技能与获取条件。
- 三列能力库内部滚动；点选只更新下方常驻详情，不弹抽屉。能力库保持原节点及滚动位置。
- 当前效果与升级结果并列：技能书按实际增加 20 熟练度计算；精通手册按选定数量预览，基础精通仍无等级上限。
- 主动技能下方只保留一套三技能栏，点目标栏直接装配、点本技能所在栏卸下。被动与生活能力没有误导性的装配动作。
- 研读、数量及确认固定在底部；耗尽显示缺少道具，按钮不跳位置。

### 一致的反馈

上述原位操作直接更新穿戴、数量、等级与状态，不再弹重复成功 toast 挡住按钮。错误提示、战斗和 NPC 场景原有必要反馈保留。

### 底栏视觉收尾

- 三页固定确认动作统一为 48px 高、文字居中、完整细边框与小圆角，不再叠加切角和圆角造成边线残缺。
- 背包“穿戴 / 使用”采用青色能源材质，“卸下 / 查看来源”用较低强调的金属灰；禁用态明确区分。
- 选择条左右留白 12px，物品原画在 44px 容器内保留四周 6px 内距；不裁切或改动实物图。
- 底栏为属性差值预留相同空间，穿戴前后不因文案换行而上下移动按钮或挤动列表。
- 360px 技能页的使用条件完整可见；更长的详情仍在自身内部滚动。能力库显示实际数量，溢出时明确提示继续上滑。
