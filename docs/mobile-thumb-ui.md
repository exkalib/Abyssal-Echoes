# 手机手区交互调整

本轮只调整游戏界面与操作逻辑，不发布、不更改版本号，不调整战斗数值、路线、存档迁移或穿戴资源。

## 画面和入口

- 营地以现有残骸场景为主体；设施用实物图标，列表内部滚动，建造、筛选、出发固定下方。
- 角色以人物为主体；六项核心状态与基因、回响、完整属性入口在同一屏。详细信息打开统一底部抽屉。
- 背包保留人物舞台，只滚动物品仓。分类和部位选择靠下；装备、物品的确认和返回固定在抽屉底部。
- 技能是三槽加三列纹章库，不再堆长详情。点击招式后在抽屉底部直接装入目标槽位，生活与被动不提供装配按钮。
- 职业、任务的分类在底部，内容独立滚动；NPC 的交互类型位于离开按钮上方。
- 地图、探索、回营复用原有动作，集中到下方，不改变返程路径或代价。

## 连续操作修复

- 滑动取消按压；点击音与震动只随实际点击发生，不因手指在列表按下就反馈。
- 抽屉遮挡时禁用来源界面；关闭恢复焦点、选中态和滚动。抽屉只淡入，不位移，固定动作不缩放。
- 采集、生产、拆解、防御、无人机更新原节点和可用态，并立即保存。
- 制作数量提供 ±1、±10 和键盘输入；拆解上限跟随剩余库存。
- 消耗品连续使用不关详情，用完原位禁用；没有实际恢复或解除效果时不可浪费药品。
- 回响、技能升级直接更新数值，不重复发成功通知；用完书籍后按钮不消失、不跳位。
- 船坞最后组件完成后立即更新总装按钮；NPC 首次发现后的靠近真正接入交谈。
- 移除营地里不带培养槽参数、永远不可用的重复催生入口；正确入口仍在菌圃各培养槽。
- Android 返回先处理剧情遮罩、详情、地图、NPC 和当前工作区，再返回主场景。原生变更需要下次重新构建 APK 才能进入安装包。
