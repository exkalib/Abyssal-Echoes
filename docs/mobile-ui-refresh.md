# 手机界面整理 · 2026-09-05

## 本轮边界

只调整现有游戏的界面与交互，不变更战斗/装备数值、剧情条件、路线解锁、云存档服务或发布渠道。沿用 ABYSS//FRAME 的深色金属、低亮青色交互、人物与场景插画，不引入另一套美术。

统一阅读顺序：当前状态 → 能做什么 → 按需展开规则。主要操作触摸区至少 44px；正文 13px、次要说明 11px、最小标签 10px。世界地图保留缩放画布、坐标与扩展命中区域，不用通用按钮尺寸挤动节点。

## 页面变化

- 营地：缩短概览，明确“设施防线”不是人物属性；固定底部“出发探索”；超过六座设施后按制造、生存、成长与远征筛选。筛选保留卡片节点，打开地图再回来恢复设施滚动位置。
- 角色：六项常用状态优先，基因锁和回响入口前置，其他八项属性折叠；没有移除属性。
- 技能/职业：图鉴与已学能力分开；先显示实际效果和装配动作，再展开细节。主职与可并行副职说明更直接，导师及晋升条件保留。
- 背包：固定分类，物品仓填满可用空间并内部滚动；人物立绘可以原位收起；穿戴动作提前到详情顶部，换装层、候选列表、对比及材料来源保留。
- 任务：一个重点目标和一句下一步；奖励、背景和其他待办按需展开，追踪切换仅更新详情和选中态。
- 设置：音效、音乐、音量、触觉、外观原位更新；存档管理独立二级页；更新和危险重置折叠；QQ群与口令仍独立一行。未改手动云同步和冷却规则。
- 商店/设施：统一设施头部、商品大小、数量控件与固定确认/关闭。商店分类、买卖、数量和结算保留工作区节点，空分类与限购有明确状态，成功结算不再弹通知覆盖确认按钮。
- NPC：操作区按内容决定高度，长任务内部滚动；简单对话不再用空面板盖住人物，底部保留“我走了”。
- 探索/地图：中文地点、已发现进度、地图/回营工具更清楚；保留原迷雾和标记动画逻辑。
- 战斗：修复职业状态挤成竖排、隐藏编号后技能名落入窄列的问题；禁用技能仍显示名字及原因；战斗记录和角色状态采用相邻排布，不再固定高度重叠。
- 核心/结局/死亡：放大条件与选择按钮，组件单列可滚动，结束后选项含义明确，死亡页采用同一套状态与行动层级。
- 开场：手环引导与当前五个菜单保持一致，男女选择及建造提示使用手机可读字号。

## 验证

使用隔离浏览器上下文，不导入或重置用户存档，不调用在线发布与云写入。

- 全量逻辑测试：`npm test`，包括剧情、装备、真实战斗数值回归、换装清单、UI契约、云存档单测。
- 33 种页面状态 × 360×640 / 390×844 / 412×915：检查页面/文档溢出、脚本异常、可见文本、触摸目标，并目视关键页面截图。
- `prototype/mobile-ui.browser.test.cjs`：营地筛选/地图往返/角色展开/五个导航的节点稳定和尺寸。
- `prototype/rpg-panels.browser.test.cjs`：技能图鉴、职业路线、背包候选和穿戴，四种宽度。
- `prototype/tasks-settings.browser.test.cjs`：任务追踪、设置持久化、音量轨道、重置取消、备份取消、云管理页面无自动联网。
- `prototype/shop.browser.test.cjs`：三种手机尺寸下的交易结算、数量、限购、空分类、稳定节点与滚动。

浏览器测试复用本地 HTTP 预览，默认 `http://127.0.0.1:4187/`；通过 `PLAYWRIGHT_MODULE` 与 `BROWSER_EXECUTABLE` 可指定现有测试运行时。

本轮仅完成本地修改和验证，未发布服务器版本或 APK。
