# 装备双路线扩充 v2

2026-09-05。按用户新增要求扩充；原装备梯度 v1 的 47 件装备与存档 ID 保留。新增 77 件，共 124 件装备、220 件物品。数值、独立原画和男女逐部位换装已接入正式背包，已完成本地验收，尚未发布。

## 成长规则

- 阶段指材料科技阶段，不是每个角色等级：锻造 → 舰装 → 场能 → 量子 → 星际。模块额外提供基础制造可做的入门款。
- 11 个系列覆盖 10 个槽：刃器和枪械同属主武器槽，其余为盾、头、胸、手、腿、脚、背、植入、模块。每个系列每阶段都有专精 / 综合两种取舍；原有旁支、结局装备不删除。
- 专精型的核心属性高于同阶段综合型；综合型必须至少有一项实际优势，且本路线升级不丢失、不降低已有主要属性。
- 全域模块属性种类按阶段为 2 / 4 / 7 / 10 / 13 / 13；量子和星际覆盖攻击、防御、生命、体力、护盾、速度、移动、暴击、暴伤、命中、闪避、穿透、吸血。星际对全部 13 项继续增值。
- 其他装备保持本部位功能：综合轻甲不超过重甲防御，综合手套不超过臂铠攻击，综合手枪不超过双手枪的攻击与射程。不会把每个槽都变成完全相同的全属性芯片。
- 新巡航手枪全部单手，可与实体盾搭配；低于同阶段进攻枪的攻击和射程。旧双手武器规则不变。
- 体力装备进入 maxStamina，目标伤害词条汇总所有装备槽；穿脱只钳制资源上限，不补满资源。暴击 100%、闪避 60%、穿透 90%、命中 100% 的原上限保持。

## 配方、获取与经济

所有新增配方注册到原科技的 un 列表；已研究该科技的旧存档自动获得配方，不重置科技、不额外要求重练。配方使用现有材料，不增加新货币、抽卡或随机词条。武器和胸甲多消耗一份结构材料，综合型增加一个布线元件。制作仍检查材料、科技、设施与等级。

入门 / 锻造 / 舰装新装备分别进入商店 1 / 2 / 4 档；全路线还进入信标 1 / 5 / 15 / 40 / 60 / 80 层装备池。后期不直接塞进低级商店。

声望继续使用现有价格函数，回售价不高于买价，最高声望买卖平价。新增装备拆解只能返回配方真正用过的材料，每种不超过单件投入的一半，避免精通和设施乘区把低成本成品变成无限原料来源。
