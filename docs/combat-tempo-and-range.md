# 速度行动条与射程精通

2026-09-08，本地实现，尚未发布。依照用户要求，近战也允许无限距离成长。没有调整敌人的固定属性，也不修改玩家存档来补发能力。

## 射程

- 新增「射程精通」：每级所有武器、徒手与有距离限制的战斗技能 +1 攻击距离，等级无上限；哈里斯材料训练或精通训练手册均可提升。
- 延续精通的 101 级超限结构：此后每级另加 0.5% 护甲穿透，最终穿透仍遵循既有属性规则。
- 原科技距离加成保留；固定距离技能也计算成长，自身技能仍不检查距离。武器类型、弹药、体力和职业要求没有取消。
- 普攻、技能可用状态和详情文案读取同一个距离加成，不重复叠加。

## 行动节奏

- 行动耗费的虚拟战斗时间为 `1 / 速度`。双方从零开始积累，同一时刻就绪时玩家优先。
- 在玩家操作窗口保存敌方行动条，执行完玩家动作后按速度比推进，处理下次玩家就绪之前的敌方行动。保存小数进度，不随机抢回合，也不对高速玩家设置连续行动上限。
- 同速交替，100:10 可连续操作 10 次后敌方行动一次；25:10 保留小数余量，长期平均 2.5:1。敌方更快时也会先手或连续行动。
- 普攻（含落空）、战技、接近、休整、战斗道具与失败逃跑共用结算入口。成功击杀、死亡、成功逃跑终止当前战斗，不追加行动；无效攻击不耗行动。
- 瘫痪、打断、防御临时增益和首领回合机制按真正到来的敌方行动机会结算。恢复护盾/再生继续沿用敌方行动后的原规则，不因玩家高速连动重复触发。
- 战斗面板显示双方速度及「可连续行动 N 次」或「行动后敌方 N 次」。旧战斗存档没有行动条时，从当前窗口开始，不追补历史敌方回合。

## 验证

- `combat-tempo.test.cjs` 由 `game.test.js` 调用，覆盖相同、十倍、非整数、反向和极端速度、开场死亡、击杀、无效动作、道具、控制效果、读档及 Lv1000 射程。
- `combat-tempo.browser.test.cjs` 在 360×640 / 390×844 / 412×915 / 520×844 验证真实近战远程攻击、技能与九次普攻累计十次行动、精通入口和底部按钮，截图在 `output/combat-tempo/`。
- 保留职业、伤害及物资断言；原来强制高阶首领一定造成伤害的测试，调整为允许速度优势获胜。战斗模拟账本从首次先手前开始记录伤害。
