# ENEMY PORTRAITS V1

战斗页全屏怪物立绘资产。22 张正式敌人图均由内置 ImageGen 生成，尺寸为 `1024 × 1536` RGBA PNG，并保留真实透明通道。

## 统一生成提示

- 用途：竖屏移动端科幻生存 RPG 的全屏战斗背景主视觉。
- 风格：写实科幻角色渲染；坠毁方舟世界；石墨、旧钛、污白、氧化橙；冷蓝轮廓光；低饱和且有真实磨损。
- 构图：单一敌人或一个明确的编队遭遇；三分之四视角；从最高点到足、尾、武器和外圈全部入画；四周保留透明边距；缩小到手机仍有清楚轮廓。
- 输出：真实透明底、干净 alpha；无地面、环境、UI、文字、标志、水印和无关角色；不裁肢、不复制肢体。
