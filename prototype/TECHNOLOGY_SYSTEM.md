# 《深渊回响》科技、资源与设施体系

## 设计目标

科技进度不是“捡到一种材料就自动知道下一项配方”，而是一条完整闭环：

```text
首次探索 → 发现产区与技术资料 → 在营地研究 → 建造/升级专用设施
        → 加工中间材料 → 制作装备或开启新区域 → 取得下一阶段资料
```

前 27 项旧科技继续承担坠毁后的残骸工业，保留原 ID、效果与剧情引用。新增 37 项未来科技，整棵树共 64 项、7 个领域、8 个文明阶段。固定资料与原型只获得一次；矿物和设施材料按天刷新。

## 七个科技领域

- 生存医疗：医疗与环境防护 → 组织打印 → 再生医学 → 共生界面 → 方舟生态核。
- 武器系统：铁制武装 → 磁轨/脉冲 → 等离子 → 惯性武器 → 蜂群武库。
- 工程制造：基础冶炼 → 钢与微电子 → 钛合金 → 分子打印 → 纳米与可编程物质 → 自复制工业。
- 能源场：应急微电网 → 同位素/超导 → 聚变 → 人工重力 → 回响耦合 → 微恒星场核。
- 动力防护：基础护具 → 护盾与外骨骼 → 重力作业骨架 → 相位层 → 星际远征壳层。
- 探测自动化：电工与扫描 → 权限/防御 → 物流无人机 → 数字孪生 → 量子协处理 → 受约束自治智能。
- 异常回响：异常频谱 → 生物耦合 → 相位晶格 → 非局域通信/记忆介质 → 时滞场 → 航迹折叠。

异常科技必须来自真实探索资料，不能从废铁配方直接跳出；自治智能保留人工授权边界，呼应守望者主线。

## 六座未来设施

| 设施 | 主要作用 | 升级方向 |
|---|---|---|
| 能源核心 | 聚变燃料封装与高级能源生产 | 同位素循环 → 聚变 → 等离子 → 回响耦合 → 微恒星 |

| 生物构造室 | 仿生基质、纳米医疗和共生装备 | 组织打印 → 再生医学 → 共生培养 → 生态核 |
| 回响观测台 | 异常材料、回响记忆与时滞设备 | 频谱 → 相位共振 → 记忆库 → 折叠信标 |
| 重力锚 | 惯性装备、相位防护和已探索路线减耗 | 人工重力 → 作业骨架 → 相位层 → 远征壳层 |

无人机只能回收玩家已经亲自到达的资源点，不会取得任务物品、蓝图或技术资料。航迹折叠只降低已经走过的路线消耗，首次探索仍需本人完成。

## 研究规则与防卡死规则

- 早期研究用时 4 小时；中期 8 小时；高阶与终局 12 小时。
- 高阶研究同时检查前置科技、探索资料、材料和研究设施是否建成且未损坏。
- 玩家能提前看见未来节点，但详情会明确指出资料地点、材料产区和缺失设施。
- 新地点全部接入旧地图并保留返营路线；入口科技只锁定目的地，不会让已在其中的玩家无法返回。
- 研究与建筑跨周目保留，科技版本升级为 v4；旧 27 项研究不会丢失。
- 科技树扩张后，基因树科技数量门槛调整为 12 / 30 / 52；v3 旧存档保留原 6 / 14 / 24 门槛。
